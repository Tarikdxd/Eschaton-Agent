### ⚡ Eschaton Code v1.2.0 Release

Next-generation terminal coding assistant bringing together the best of OpenCode, Freebuff, Claude Code, and Google Antigravity.

- **Exact Freebuff / OpenCode TUI:** Full alternate screen buffer, interactive status header, real-time diff viewer, and multiline command prompt.
- **Complete Monorepo Source:** Full CLI, SDK, agents, common libraries, and web tooling.
- **Claude Code Architecture:** Tool execution for Bash, File Read, File Edit, File Write, Glob, Grep.
- **Native Antigravity Integration:** Automatic environment discovery (`~/.gemini/antigravity`), installation ID binding, and brain directory sync.

#### Instant Installation:
```bash
npm install -g https://github.com/Tarikdxd/Eschaton-Code/releases/download/v1.2.0/tarikdxd-eschaton-code-1.2.0.tgz
```

#### Launch:
```bash
eschaton
```
*(or run `freebuff` / `opencode`)*
