Çekirdek Mimari

Dört katmanlı güvenli orkestrasyon

Dış ajan yalnızca repo linkini okur; Eschaton-Agent kurulumdan %10 kota korumasına kadar tüm köprüyü otonom yönetir.

01 / BRIDGE

Hibrit Electron CDP + UI Köprüsü

Birincil olarak Antigravity’nin Electron CDP/DOM portu üzerinden fareyi meşgul etmeden arka planda çalışır; port kapalıysa UI otomasyonu yedeğine geçer.

02 / WORKSPACE

Akıllı Proje / Workspace Seçici

Dış ajanın çalıştığı dizini ve açık Antigravity pencerelerini tarayarak doğru projeyi otomatik eşleştirir, odaklar veya açar.

03 / BENCHMARK ROUTER

Canlı Benchmark Model Seçici

SWE-bench Verified, Aider Polyglot, LMArena ve LiveCodeBench verilerini senkronize ederek her promptun görev tipine en uygun modeli seçer.

04 / 10% USAGE SHIELD

%10 Korumalı Token & Usage Kalkanı

Gönderim öncesi token maliyetini hesaplar. Taşma riski veya %10 sınırını aşma ihtimali varsa promptu engeller, kotayı asla sıfırlamaz.

Terminal / CLI Kurulum & Görev Devri 
git clone https://github.com/Tarikdxd/Eschaton-Agent.git
cd Eschaton-Agent && pip install -e .
eschaton connect
eschaton delegate "Auth hatasını bul ve test yaz" \
  --project "$(pwd)" --role deep_debugger

MCP Araçları

Dış Ajanlara Sunulan 5 Standart Araç

MCP Tool Görev
antigravity_status CDP / UI bağlantı durumunu, açık projeleri, modelleri ve kalan % kotayı okur.
antigravity_select_project Bilgisayardaki doğru proje dizinini bulup Antigravity ile eşleştirir veya açar.
antigravity_select_best_model SWE-bench, Aider, LMArena ve LiveCodeBench verilerine göre en iyi modeli seçer.
antigravity_check_usage_shield Gönderim öncesi token & %10 koruma kalkanı doğrulaması yapar.
antigravity_delegate_task Proje seçimi + model seçimi + %10 kalkanı + uzman rol ile görevi Antigravity’ye iletir.
